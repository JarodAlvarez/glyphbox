# GLYPHBOX

A 1-bit fantasy console you can build yourself. Games are written in Lua, printed as Aztec codes on credit-card-sized cards, and read by a camera in the console's card slot.

| | |
|---|---|
| Display | 128 × 128, 1-bit |
| Input | D-pad, action button, menu button |
| Audio | 2 cart channels (square, triangle, noise) + system channel |
| Sprites | 128 tiles, 8 × 8, 1-bit |
| Frame rate | 30 fps |
| Carts | Lua, up to 8 cards |

**Website:** https://jarodalvarez.github.io/glyphbox/

This repository will hold the devkit, the docs and cart format spec, example and original games, and the hardware files for building a console. They're being moved in now.

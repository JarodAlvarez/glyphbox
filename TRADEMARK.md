# GLYPHBOX name and logo

"GLYPHBOX" and the GLYPHBOX logo (the nested-squares mark with five dots) belong to Gureedo. The open licenses in this repository don't cover them.

**You can:**
- say your game runs on GLYPHBOX, or is "made for GLYPHBOX"
- use the logo to link to the project, or to show that a game or build is GLYPHBOX-compatible
- call a console you built yourself from these files a GLYPHBOX

**Please don't:**
- use the name or logo for a product you sell
- name a modified or forked console, emulator or tool "GLYPHBOX", or anything that could be mistaken for the official project
- change the logo, or use it in a way that suggests Gureedo endorses something without asking

If you're unsure, open an issue and ask.

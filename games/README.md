# Games

Original GLYPHBOX games by Gureedo. Each folder has the Lua source and a built `.gbcart`.

| Game | Folder | Cards |
|---|---|---|
| Sunset Run | [sunset-run](sunset-run/) | 8 |
| Glyph Golf | [glyph-golf](glyph-golf/) | 8 |
| Chess | [chess](chess/) | 8 |
| Tennis | [tennis](tennis/) | 4 |
| Runner | [runner](runner/) | 2 |

Card printing is part of the devkit, which is on its way.

These games use `hint()`, which draws the action-button graphic. It needs console software from November 2026 or later.

The games are free to play and study. See [LICENSE.md](../LICENSE.md).

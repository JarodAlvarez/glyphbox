GLYPHBOX is a 1-bit console you can build yourself, with a 128 × 128 screen, a D-pad and one button. Games are written in Lua and compiled onto credit-card-sized cards, and a camera in the card slot reads them.

A game is a folder of Lua and art. The devkit compiles it into a cart and prints the cart onto cards. The console reads the cards in any order and boots the game.

1WRITE

_init, _update and _draw. Sprites, a 16 × 16 tile map and two sound channels.

2BUILD

glyph build compiles the game and tells you how many cards it needs.

3PRINT

Up to 8 cards per game, each with 800 bytes of Aztec code.

4SCAN

Slide each card into the slot. The screen follows the card in.

A 3D-printed case around a Raspberry Pi 3, with a camera under the card slot and a controller that docks on magnets. Its boot screen and menus use the same 1-bit screen and font as the games.

    Start in the browser with nothing to install: the lessons and the Playground run the real console beside your code. When you're ready for cards, the devkit builds, counts and prints them.

    -- game.lua
function _init()
  x = 60
end

function _update()
  if btn(BTN_L) then x = x - 2 end
  if btn(BTN_R) then x = x + 2 end
  if btnp(BTN_A) then sfx(0, 60, 6, 0, 4) end
end

function _draw()
  cls(0)
  circf(x, 64, 6, 1)
end
